# First Supplier Search Profile

## Objective

Use BEACON historical TikTok/web trend signals to prioritize existing supplier catalogs instead of starting product discovery from zero.

## Initial category focus

1. Automotive accessories
2. Driver convenience
3. Cleaning and utility
4. Organization and storage

## Preferred product attributes

- Finished product already available
- Resale or affiliate authorization available
- Supplier-managed fulfillment
- Inventory synchronization available
- Tracking synchronization available
- Clear returns process
- Product value visually demonstrable in 15-20 seconds
- Obvious problem-to-solution transformation
- Low sizing complexity
- Low claim burden
- Low expected return risk
- Positive contribution margin after all variable costs

## Historical priors

The existing seed currently gives extra weight to:

- car seat-gap organizer/filler style products;
- automotive convenience products;
- cleaning/utility products with visible before/after results;
- organization products that demonstrate value quickly.

Historical evidence is not sufficient for launch approval.

## First supplier ecosystem

Prefer Shopify Collective for the first controlled proof when the connected store is eligible because the system is designed around existing supplier inventory, supplier fulfillment, inventory synchronization, order routing, tracking synchronization, and payment after sale.

Secondary supplier-network candidates for later evaluation include dropshipping marketplaces that expose automotive catalogs and structured supplier relationships.

## AXIS search request

Find authorized supplier products matching the category and attribute profile above. Return only products for which resale/affiliate permission, active inventory, fulfillment, tracking, returns, and landed economics can be validated.

## BEACON ranking additions

Every candidate receives:

- historical_signal_match (0-100)
- fresh_evidence_strength (0-100)
- exploit_or_explore
- current demand evidence
- contribution margin estimate
- supplier reliability evidence
- return-risk estimate
- short-form demonstration score
- cheapest falsification test

## VERITY gate

No product proceeds based on trend history alone. VERITY must independently confirm authorization, policy compliance, costs, margin, fulfillment, tracking, returns, and any claims before DIRECTOR or AXIS creates a live listing.
